# KaamSetu Admin Dashboard (कामसेतु एडमिन कंट्रोल सेंटर)

यह KaamSetu का स्वतंत्र और सुरक्षित एडमिन पोर्टल है, जहां एडमिन:
1. **कारीगरों का संपूर्ण कार्य इतिहास (Worker Work History)**: कब, किस तारीख को, किस दिन, कहाँ पे काम किया, किस ग्राहक के लिए, और कितना चार्ज था।
2. **काम पर बुलाने वाले / मालिकों का हायरिंग इतिहास (Employer Hiring History)**: किस ग्राहक ने कब बुलाया, किसको बुलाया, किस काम के लिए बुलाया, और क्या स्थिति है।
3. **मास्टर जॉब्स लेज़र (Master Bookings Ledger)**: पूरे सिस्टम की सभी बुकिंग्स को फ़िल्टर करना, स्थिति बदलना (स्वीकृत, चालू, पूरा हुआ, रद्द), और डिलीट करना।
4. **एनालिटिक्स व आंकड़े (Overview Analytics)**: कुल कारीगर, कुल बुकिंग्स, कुल व्यापार मूल्य (₹), शहर व श्रेणी विवरण।

---

## कैसे चलाएं (How to Run)

### 1. डिपेंडेंसी इंस्टॉल करें (Install Dependencies)
```bash
cd admin-dashboard
npm install
```

### 2. डेवलपमेंट सर्वर शुरू करें (Start Dev Server)
```bash
npm run dev
```
डैशबोर्ड **http://localhost:5174** पर खुलेगा।
